# 📦 TyrlovInventoryCRM — Система управления складом

**TyrlovInventoryCRM** — это современное десктопное приложение для управления складскими запасами, разработанное на C# WPF с использованием паттерна MVVM. Программа предоставляет удобный интерфейс для учета товаров, аналитики и генерации отчетности.

## ✨ Ключевые возможности

* **📊 Интерактивный дашборд:** Визуализация данных склада с помощью круговых диаграмм (LiveCharts2) и мгновенный расчет тотальной стоимости всех запасов.
* **⚠️ Контроль критических остатков:** Автоматическое отслеживание и вывод на дашборд топ-5 товаров, количество которых опустилось ниже 5 штук.
* **🔍 Умный поиск:** Моментальная фильтрация товаров по названию или категории прямо в таблице без перезагрузки страницы.
* **🌗 Темная и светлая темы:** Поддержка смены визуального оформления "на лету" с автоматическим сохранением выбора пользователя при перезапуске программы.
* **📄 Экспорт отчетов:** Поддержка выгрузки текущих остатков в **Excel** (с автоформатированием ячеек) и в **PDF** (готовый документ для печати).
* **⚡ Локальная БД:** Быстрая и надежная база данных на основе Entity Framework Core (SQLite).

## 🛠 Стек технологий

* **Язык:** C# (.NET 10)
* **UI Фреймворк:** WPF (Windows Presentation Foundation)
* **Архитектура:** MVVM (CommunityToolkit.Mvvm)
* **База данных:** SQLite + Entity Framework Core
* **Графики:** LiveChartsCore.SkiaSharpView.WPF
* **Отчеты:** ClosedXML (Excel), QuestPDF (PDF)

## 🚀 Установка и запуск (Готовая версия)

Вам не нужно устанавливать среду разработки или компилировать код, чтобы протестировать CRM.

1. Перейдите в раздел [Releases](https://github.com/ilykaoruko/TyrlovInventoryCRM/releases) справа на странице проекта.
2. Скачайте последний архив `TyrlovInventoryCRM_v1.0.zip`.
3. Распакуйте архив в любую удобную папку на вашем ПК.
4. Запустите файл `TyrlovInventoryCRM.exe`.

*Примечание: База данных (чистая) будет создана автоматически рядом с исполняемым файлом при первом запуске.*
